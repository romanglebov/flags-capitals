# Древо государств

Интерактивная лента-древо: из каких государств сложилась страна, с кем объединялась и на какие части распадалась.
Вертикальная ось — время: вверху настоящее, ниже — прошлое, вплоть до самых ранних известных фактов.

Открыть: `history/index.html` (работает и как статический сайт, и прямо из файла). Страна выбирается в шапке
или через адрес: `history/#ru`, `history/#kazan`, `history/#ussr`.

## Как это устроено

```
history/
  index.html        разметка, стили, подключение файлов
  js/engine.js      хранилище (HistoryDB), даты, граф преемственности
  js/flags.js       отрисовка флагов и условных символов
  js/app.js         построение древа, линии, карточки
  data/world.js     современные государства и внешние участники событий
  data/russia.js    история России
  tools/validate.js проверка данных
```

Данные — это обычные JS-файлы, которые вызывают `HistoryDB.add({...})`. Чтобы добавить страну:

1. Создайте `history/data/<страна>.js`.
2. Подключите его в `index.html` перед `js/app.js`.
3. Запустите `node history/tools/validate.js <id-страны>` — он покажет главную линию и ошибки в ссылках и датах.

Записи с одинаковым `id` из разных файлов **дополняют** друг друга: массивы (правители, документы, флаги…)
склеиваются, остальные поля перезаписываются. Поэтому, например, файл `ukraine.js` может расширить краткую
карточку `ua` из `world.js`, не трогая её.

## Модель данных

Есть два вида записей: **государства** (сущности) и **события**, которые их связывают.
Древо строится автоматически: для выбранной страны берутся все события, где она «на выходе», их «входы»
становятся предками, и так рекурсивно до самого начала.

### Государство

```js
{
  id: 'ussr',                       // уникальный, латиницей
  name: 'Союз Советских Социалистических Республик',
  short: 'СССР',                    // короткое имя для подписей (необязательно)
  start: '1922-12-30',              // дата: 1922, '1922', '1922-12', '1922-12-30', '-500' (до н. э.)
  end: '1991-12-26',                // null — существует сейчас
  startLabel: 'ок. 1263',           // как показывать дату начала, если она приблизительная
  endLabel: '...',
  color: '#C0392B',                 // цвет линии (иначе подбирается автоматически)
  type: 'Форма правления',
  summary: 'Краткое описание',
  origin: 'Как возникло, если события-источника нет',
  capitals:  [{ name: 'Москва', from: '1922' }],
  flags:     [{ from: '1923-11-12', flag: { type: 'ussr' }, name: 'Название', note: 'Пояснение' }],
  religions: [{ name: 'Государственный атеизм', kind: 'atheism', from: '1922', note: '...' }],
  rulers:    [{ name: 'Владимир Ленин', title: 'Председатель СНК', from: '1922-12-30', to: '1924-01-21', note: '...' }],
  documents: [{ date: '1924-01-31', title: 'Конституция СССР', text: '...' }],
  notes:     [{ date: '1957-10-04', text: 'Запуск первого спутника' }],
}
```

`kind` религии задаёт цвет полосы рядом с линией: `pagan`, `orthodox`, `islam`, `tengri`, `buddhism`,
`atheism`, `secular`, `other`.

### Событие

```js
{
  id: 'e1991',
  date: '1991-12-26',
  dateLabel: '8–26 декабря 1991',   // необязательная подпись
  type: 'split',
  title: 'Распад СССР',
  text: 'Описание',
  from: ['ussr'],                   // кто «вошёл» в событие
  to: ['ru', 'ua', 'by', ...],      // кто «вышел»
  primary: 'ussr',                  // главный предшественник (для главной линии), по умолчанию — первый в from
  involves: [],                     // участники без слияния: войны, договоры, зависимость
  partial: false,                   // true — передача территории: участники не становятся предками
  disputed: 'Текст',                // статус оспаривается (показывается предупреждение)
  documents: [{ title: 'Беловежские соглашения', date: '1991-12-08' }],
}
```

Как `from` и `to` описывают разные случаи:

| Случай | from | to |
|---|---|---|
| Объединение (`merge`) | `[a, b]` | `[c]` |
| Распад (`split`) | `[a]` | `[b, c, d]` |
| Переименование, революция (`transform`, `revolution`) | `[a]` | `[b]` |
| Присоединение (`absorb`): *b* вошло в *a* | `[a, b]` | `[a]` |
| Выделение (`spawn`): из *a* выделилось *b* | `[a]` | `[a, b]` |
| Передача земель (`territory`, `partial: true`) | `[кто отдал]` | `[кто получил]` |
| Война, договор, зависимость (`battle`, `treaty`, `dependency`, `religion`) | — | — (`involves`) |

Остальные типы: `founding`, `collapse`. Если у государства нет события-источника или события-конца,
древо само добавит узлы «Возникновение» и «Конец» по датам `start` и `end`.

### Флаги

```js
{ code: 'ru' }                                                   // современный флаг из ../flags/<code>.svg
{ type: 'img', src: 'images/flag.svg' }                          // любой файл
{ type: 'stripes', colors: ['#000', '#F7D117', '#FFF'], dir: 'h' } // полосы, dir: 'h' | 'v'
{ type: 'plain', color: '#CC0000' }
{ type: 'canton', text: 'РСФСР', bg: '#CC0000', color: '#F2C230', box: '#1F4FA0' } // надпись в крыже
{ type: 'ussr' }
{ type: 'symbol', glyph: 'eagle', bg: '#B22222', fg: '#F2C230', conventional: true }
```

Глифы: `trident`, `eagle`, `tamga`, `crescent`, `bell`, `cross`, `spear`, `dragon`, `wheel`, `star`.
`conventional: true` помечает условный символ (на плитке появляется штриховка) — используйте его,
когда государственного флага не было или он неизвестен. Без флага показываются инициалы.

## Принципы наполнения

- Даты до 1918 года (для России) — по григорианскому календарю; старый стиль указывается в `dateLabel`.
- Спорные и непризнанные изменения границ отмечаются полем `disputed` с нейтральным описанием позиций.
- Легендарные сведения (например, призвание варягов) подаются как сведения источника, с оговоркой.
